# Search shell controls — mock visual contract

Story: `Prototypes / Direct Selection Tag Picker / One selected`, with the Tags panel open. Review at 1280 × 800 desktop and 820 × 1100 iPad widths.

- The blue banner remains one row. Exit, scope, Tags, and Type read as quiet borderless toolbar controls. The query field retains a visible boundary and the remaining banner width.
- The applied-tag removal chip is borderless and visually subordinate to the Search controls.
- Keyboard focus remains explicitly visible on a toolbar control.
- The Tags panel opens beneath its trigger, remains on screen, and does not obscure the controls or create page-level horizontal overflow.

The border treatment is the design owner's proposed contract for this Storybook proof; it has not been approved as a production design.
